# 개요

본 매뉴얼에서는 HD현대로보틱스 (HDR) ROS2 드라이버에 대한 설명을 제공합니다.

HDR ROS2 드라이버는 HD현대로보틱스 산업용 로봇 제어기(Hi6 시리즈)와 ROS2 간의 원활한 통합을 가능하게 하며, 시뮬레이션과 실제 로봇 제어 기능을 모두 제공합니다.
