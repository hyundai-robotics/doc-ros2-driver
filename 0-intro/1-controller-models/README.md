# 지원 제어기 모델
ROS2 기능을 공식적으로 지원하는 HD현대로보틱스 Hi6 제어기 모델은 아래와 같습니다.

- Hi6-N10
- Hi6-N20
- Hi6-N00(HK)
- Hi6-N00-60(HK)
- Hi6-N30(HK)
- Hi6-N80(HK)
- Hi6-T15

**제어기 요구사항**:
- SW 버전 버전: **60.32-00** 이상
- 동작 모드: **REMOTE 모드**

> ⚠️ **참고:** HD현대로보틱스 ROS2 드라이버는 **Hi5** 제어기 시리즈를 **지원하지 않습니다**.
