# 지원 제어기 모델
ROS2 기능을 공식적으로 지원하는 HD현대로보틱스 Hi6 제어기 모델은 아래와 같습니다.

- Hi6-N10
- Hi6-N20
- Hi6-N00(HK)
- Hi6-N30(HK)
- Hi6-N80(HK)
- Hi6-T15

**제어기 요구사항**:
- SW 버전 버전: **60.34-00** 이상 (10월 중 배포 예정)
- 동작 모드: **REMOTE 모드**

> ⚠️ **참고:** HD현대로보틱스 ROS2 드라이버는 **Hi5** 제어기 시리즈를 **지원하지 않습니다**.

> ⚠️ **실시간 인터페이스**: 2025년 11월 예정 (모션 제어, 상태 피드백 및 I/O 작업을 위한 2ms 주기 제어)
