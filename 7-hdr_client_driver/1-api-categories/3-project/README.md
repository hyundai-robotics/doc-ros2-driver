# 7.1.3 项目 API

### 概述

项目 API 类别为 HD 现代机器人控制器提供项目和作业管理功能。这些 API 使得监控项目执行状态、查询作业信息和管理作业成为可能。

### 可用项目 API

| 函数 | 描述 |
|----------|-------------|
| `GetProjectRgen` | 查询当前项目执行状态 (0: 未运行, 1: 正在运行, 2: 暂停) |
| `GetProjectJobsInfo` | 检索注册在项目中的所有作业的元数据 (名称, 路径, 修改状态) |
| `PostProjectReloadUpdateJobs` | 重新加载并同步外部修改的作业以更新内存中的作业状态 |
| `PostProjectDeleteJob` | 从项目路径中删除指定的作业文件 |
