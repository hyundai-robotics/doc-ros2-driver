# 10. ROS2 驱动程序执行和机器人控制

### 概述

本节提供了使用 ROS2 驱动程序操作 HD Hyundai Robotics 机器人的全面指南。

HD Hyundai Robotics ROS2 系统提供以下控制方法：

- **MoveIt2 集成**：运动规划和执行
- **ros2_control**：硬件接口控制
- **ROS2 服务**：控制器 API 访问
