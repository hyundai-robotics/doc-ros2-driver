# 1.1 支持的控制器模型
官方支持 ROS2 功能的 HD 现代机器人 Hi6 控制器模型如下：

- Hi6-N10
- Hi6-N20
- Hi6-N00(HK)
- Hi6-N00-60(HK)
- Hi6-N30(HK)
- Hi6-N80(HK)
- Hi6-T15

**控制器要求**：
- 软件版本：**60.32-00** 或更高（计划于十月发布）
- 操作模式：**REMOTE mode**

Hi7 控制器系列，包括未来的型号和支持计划，一旦最终确定，将立即在此列表中更新。

> ⚠️ **注意：** HD 现代机器人 ROS2 驱动程序**不支持** **Hi5** 控制器系列。
